# رِفاد | Hospital Facilities Management

واجهة ويب عربية أولية لنظام إدارة مرافق المستشفيات (CAFM/CMMS)، مبنية باستخدام HTML وCSS وJavaScript دون اعتماديات خارجية.

## مميزات النموذج الأولي

- لوحة تحكم تنفيذية ومؤشرات تشغيلية تجريبية.
- سجل أوامر العمل مع البحث والتصفية وتغيير الحالة وعرض التفاصيل وإضافة أمر جديد.
- سجل الأصول الهندسية مع البحث والتصفية وإضافة أصل.
- خطط الصيانة الوقائية التجريبية.
- أقسام المباني والمواقع، المقاولين واتفاقيات مستوى الخدمة (SLA)، السلامة والامتثال، قطع الغيار والمخزون، والتقارير.
- تصدير أوامر العمل والأصول إلى CSV.
- واجهة عربية RTL ومتجاوبة مع الجوال.
- حفظ بعض التعديلات محليًا في متصفح المستخدم عبر `localStorage`.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح. لا يلزم تثبيت حزم.

## نشر الموقع باستخدام GitHub Pages

1. افتح إعدادات المستودع: **Settings → Pages**.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
4. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages. قد يستغرق النشر بضع دقائق.

## حدود النسخة الحالية

هذه نسخة عرض (prototype) تستخدم بيانات افتراضية، وليست نظامًا جاهزًا للاستخدام التشغيلي الفعلي. لا تحتوي على خادم أو قاعدة بيانات مشتركة أو تسجيل دخول أو صلاحيات مستخدمين أو سجل تدقيق دائم. تحفظ الإضافات في متصفح المستخدم فقط، وقد لا تتوفر على جهاز آخر أو بعد مسح بيانات المتصفح.

**لا تدخل بيانات مرضى أو بيانات حساسة أو بلاغات تشغيلية حقيقية في هذه النسخة.** قبل استخدامها داخل المستشفى، يلزم بناء API وقاعدة بيانات مؤمنة، وإدارة صلاحيات حسب الدور والموقع، وسجل تدقيق ونسخ احتياطي، واختبارات أمنية، وتعريف متطلبات الاعتماد والامتثال الخاصة بالمنشأة.

## خطة التطوير المقترحة

1. اعتماد نموذج البيانات والتصنيفات وسير الموافقات.
2. تطوير Backend وقاعدة بيانات وواجهات API.
3. إضافة المصادقة وصلاحيات المستخدمين حسب الدور والموقع.
4. إضافة الإشعارات وتقويم الصيانة الوقائية وإدارة SLA.
5. دعم المرفقات وقوائم الفحص وقطع الغيار والتكاليف.
6. إعداد تقارير قابلة للتخصيص وتكاملات أنظمة المستشفى.
7. اختبارات وظيفية وأمنية وبيئة نشر تجريبية.

## الترخيص

لم تُحدّد رخصة بعد. اختر رخصة مناسبة قبل إعادة الاستخدام أو التوزيع.
