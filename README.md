# رِفاد | Hospital Facilities Management

واجهة أولية تفاعلية لنظام إدارة مرافق المستشفيات (CAFM/CMMS)، مبنية حاليًا كواجهة ويب مستقلة باستخدام HTML وCSS وJavaScript دون اعتماديات خارجية.

## المزايا في النموذج الأولي
- لوحة تحكم تنفيذية ومؤشرات تشغيلية.
- سجل أوامر العمل مع البحث والتصفية وإنشاء أمر جديد.
- سجل أصول هندسية مع البحث والتصفية وإضافة أصل.
- عرض خطط الصيانة الوقائية والاستحقاقات.
- أقسام المباني والمواقع، المقاولين وSLA، السلامة والامتثال، المخزون، والتقارير.
- تصدير أوامر العمل إلى CSV.
- واجهة عربية RTL ومتجاوبة مع الجوال.

## التشغيل
افتح `index.html` مباشرة في المتصفح. لا يلزم تثبيت حزم في هذه النسخة.

## مهم قبل الاستخدام الفعلي
هذه نسخة عرض (prototype) تستخدم بيانات افتراضية، ولا تحتوي على خادم أو قاعدة بيانات أو تسجيل دخول أو صلاحيات أو سجل تدقيق دائم. الإضافات تحفظ في ذاكرة الصفحة فقط، ولا تستخدم لإدارة أعمال سريرية أو تشغيلية حقيقية. قبل الإنتاج يلزم بناء API وقاعدة بيانات، وإدارة صلاحيات، وسجل تدقيق، ونسخ احتياطي، واختبارات أمنية، وتعريف متطلبات الاعتماد والامتثال المعمول بها لدى المستشفى.

## خطة تطوير مقترحة
1. اعتماد نموذج البيانات والتصنيفات وسير الموافقات.
2. Backend وقاعدة بيانات علائقية وواجهات API.
3. مصادقة وصلاحيات حسب الدور والموقع.
4. إشعارات وSLA وتقويم الصيانة الوقائية.
5. رفع المرفقات، قوائم الفحص، قطع الغيار، والتكاليف.
6. تقارير قابلة للتخصيص وتكاملات أنظمة المستشفى.
7. اختبارات، مراجعة أمنية، وبيئة نشر تجريبية.
